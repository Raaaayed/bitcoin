# بناء وكيل ذكاء اصطناعي للتداول بانضباط مخاطر

هذا النموذج الأوّلي يطبّق المتطلبات التالية بشكل صريح:

- **Win rate > 50%** عبر قياس الأداء بعد كل مجموعة صفقات.
- **Risk/Reward > 1:2** عبر تثبيت `reward_to_risk = 2.0` كحد أدنى.
- **Drawdown control** عبر إيقاف فتح صفقات جديدة عند تجاوز حد السحب الأقصى.
- **Capital allocation discipline** عبر ضبط المخاطرة لكل صفقة وحدّ التعرض الكلي للمحفظة.

## الملف الرئيسي

- `risk_managed_agent.py`: يحتوي على:
  - `RiskManagedAgent` لتخطيط الصفقة عند مرور بوابات المخاطر.
  - `AgentConfig` لضبط السياسات.
  - `score_strategy` لتقييم الأداء: معدل الربح، نسبة العائد/المخاطرة، أكبر سحب.

## طريقة التشغيل

```bash
python3 contrib/ai_trading_agent/risk_managed_agent.py
```

## دمج النموذج مع نموذج ذكاء اصطناعي فعلي

يمكنك استبدال `TradeSignal(confidence, direction)` بمخرجات نموذج ML/LLM كالتالي:

1. النموذج يتنبأ بالاتجاه (`+1` أو `-1`) والثقة.
2. الوكيل يمرّر الإشارة إلى `plan_position`.
3. إذا فشلت أي بوابة مخاطر، لا يتم فتح الصفقة.
4. يتم تسجيل نتيجة الصفقة في `score_strategy` لمراقبة الأهداف.

> ملاحظة: هذا نموذج تعليمي/هندسي وليس نصيحة استثمارية.
